# inquiry QA

## 1. 画面表示

- [ ] **設定画面からお問い合わせ画面に遷移できる**: 設定画面「アプリについて」セクションの「お問い合わせ」セルタップでInquiryPageに遷移し、AppBarタイトル「お問い合わせ」が表示される。
- [ ] **初期表示時は送信ボタンが非活性**: メールアドレス・お問い合わせの種類・内容が全て未入力の状態では「送信する」ボタンがタップ不可（`isFormFilled == false`）。

---

## 2. 入力・バリデーション

- [ ] **メールアドレス未入力で送信するとエラー表示**: メール欄が空のまま送信操作をすると「メールアドレスを入力してください」が赤背景のエラー表示エリアに出る。
- [ ] **メールアドレスの形式が不正だとエラー表示**: `abc` のような不正な形式で送信すると「メールアドレスの形式が正しくありません」が表示される。
- [ ] **お問い合わせの種類が未選択だとエラー表示**: カテゴリ未選択のまま送信すると「お問い合わせの種類を選択してください」が表示される。
- [ ] **お問い合わせ内容が未入力だとエラー表示**: 内容欄が空のまま送信すると「お問い合わせ内容を入力してください」が表示される。
- [ ] **お問い合わせの種類を選択するとチップが選択状態になる**: 「不具合報告」「操作方法について」「ご要望・改善要望」「その他」の4チップから1つタップすると背景色・枠線が変化して選択状態を示す。

---

## 3. 送信

- [ ] **必須項目入力後に送信ボタンが活性化する**: メールアドレス・内容を入力しカテゴリを選択すると「送信する」ボタンがタップ可能になる。
- [ ] **送信中はボタンラベルが「送信中...」になり非活性化する**: 送信処理中はボタンのラベルが変わり、連続タップができない。
- [ ] **送信成功時はトースト表示後に画面が閉じる**: 正常系で送信すると「お問い合わせを送信しました」のグローバルトーストが表示され、画面がpopされ設定画面に戻る。
- [ ] **送信失敗時はエラーメッセージが表示され画面に留まる**: `functions.submitInquiry` が例外を投げた場合（オフライン状態など）、画面を閉じずに例外内容がそのままエラー表示エリアに表示される。
