- [ ] **メールアドレス未入力で送信するとエラー表示**: メール欄が空のまま送信操作をすると「メールアドレスを入力してください」が赤背景のエラー表示エリアに出る。
- [x] **メールアドレスの形式が不正だとエラー表示**: `abc` のような不正な形式で送信すると「メールアドレスの形式が正しくありません」が表示される。

- [x] **お問い合わせの種類を選択するとチップが選択状態になる**: 「不具合報告」「操作方法について」「ご要望・改善要望」「その他」の4チップから1つタップすると背景色・枠線が変化して選択状態を示す。

## 3. 送信

- [x] **必須項目入力後に送信ボタンが活性化する**: メールアドレス・内容を入力しカテゴリを選択すると「送信する」ボタンがタップ可能になる。
- [x] **送信中はボタンラベルが「送信中...」になり非活性化する**: 送信処理中はボタンのラベルが変わり、連続タップができない。
- [x] **送信成功時はトースト表示後に画面が閉じる**: 正常系で送信すると「お問い合わせを送信しました」のグローバルトーストが表示され、画面がpopされ設定画面に戻る。
- [ ] **送信失敗時はエラーメッセージが表示され画面に留まる**: `functions.submitInquiry` が例外を投げた場合（オフライン状態など）、画面を閉じずに例外内容がそのままエラー表示エリアに表示される。

（未実行）
