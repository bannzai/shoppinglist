# グループ招待機能

## 概要
招待コードベースのグループ招待機能。8桁の英数字コードを生成→共有→受信者がコードを入力してグループに参加する。

## 画面
- `GroupInvitationAcceptPage`: 招待コード入力画面
  - Settings画面の「招待コードでグループに参加」から遷移
  - 8桁の招待コードを入力し「参加する」ボタンで `AcceptGroupInvitation` を呼び出してグループに参加
  - 成功時はホーム画面に遷移
  - エラー時（期限切れ等）はエラーメッセージを表示

## 招待フロー
1. 既存メンバーが `ShoppingListSettingPage` の「グループに招待」ボタンをタップ
2. `CreateGroupInvitation` で8桁の招待コードを生成
3. ダイアログに招待コードが表示され、コピーして共有
4. 受信者がSettings画面の「招待コードでグループに参加」をタップ
5. `GroupInvitationAcceptPage` でコードを入力し「参加する」で完了

## 招待コード形式
英大文字 + 数字の8桁（例: `ABCD3456`）

## 有効期限
招待コードの有効期限は7日間。期限切れ後はエラーメッセージが表示される。

## グループ名の必須化 (Issue #432)
名称未設定のグループ同士の混同（無名グループに招待された後、自分にも無名グループがある状態）を防ぐため、グループ招待にはグループ名の登録を必須とする。

- グループ名が未設定（null・空白のみ）のグループでは招待コードを発行できない。
  - `GroupSettingPage` の招待ボタン: 「招待する前にグループ名を設定してください」とトーストで促す（同画面のグループ名入力欄で設定可能）。
  - `ShoppingListSettingPage` の招待: 同メッセージ + 「グループ設定」アクション付きトーストで `GroupSettingPage` へ誘導する。
- 名前登録済みかの判定は `Group.hasRegisteredName`（`lib/entity/group.dart`）に集約。
- グループ作成画面（`GroupCreatePage`）では名前を必須化（空だと「作成する」ボタンが無効）。作成直後の自動招待でも名前が確定済みになる。
- 初回に自動作成されるソログループ（`name: null`）は通常利用は従来どおりで、招待しようとしたときだけ名前を要求される。
