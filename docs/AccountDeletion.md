# アカウントの削除について

アプリ「買い物リスト - 家族と共有」（デベロッパー: bannzai）のアカウント削除手順と、削除されるデータについて説明します。

## アプリからアカウントを削除する手順

1. アプリを起動する
2. 画面右上の「設定」を開く
3. 画面下部の「アカウントを削除する」をタップする
4. 確認ダイアログで「削除する」をタップする

削除を実行すると、その場でアカウントが削除され、アプリは終了します。再度アプリを開くと、サインインしていない状態から始まります。

サインインしてから時間が経っている場合、セキュリティのため再ログインを求められることがあります。その場合は画面の案内に従って再度サインインしてから、もう一度削除操作を行ってください。

## 削除されるデータ

アカウント削除の操作により、次のデータが削除されます。

- アカウント情報（Firebase Authentication のユーザーアカウント）
- サインインに使用した認証情報（Apple ID / Google アカウントとの連携）
- メールアドレス、ユーザー ID

これらは削除操作と同時に削除され、復元できません。

## 削除後も保持されるデータ

グループで共有している買い物リスト、アイテム、カテゴリ、店舗の情報は、**同じグループの他のメンバーが引き続き利用するため保持されます**。これらのデータは、削除されたアカウントとの結び付きを失い、個人を特定できない状態になります。

グループを他の誰とも共有していない場合、これらのデータはどのアカウントからも参照されなくなります。

保持期間の定めはありませんが、共有しているデータも含めて完全な削除を希望される場合は、下記の連絡先までご連絡ください。ご連絡から 30 日以内に対応します。
