# 調査結果・issue・プランに agent が優先度や順位を付けない

issue を作った時に「優先度（提案）」の節と「最優先」「★」の印を入れ、owner に却下された。

**なぜ:** 優先度は owner (または後続の agent) が決めるもので、agent の主観の重み付けは判断を誘導する。

**どう使う:** 調査結果・issue・レポート・プランでは、見つけた事実と該当箇所を分類して並べるだけにする。「優先度」「最優先」「(高)(中)(低)」「★」のような印や、おすすめの順序を入れない。順序が要る時は owner に決めてもらう。
