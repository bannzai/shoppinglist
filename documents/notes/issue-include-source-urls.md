# 機能を提案する issue には、参考にしたアプリと根拠の URL を書く

owner から、issue を作る時は参考にしたアプリのリンク・根拠・参考にした記事の URL を本文に載せるよう求められた。

**なぜ:** 後から issue を読み返した時に、なぜその機能を検討したのかと、その出典を追えるようにするため。

**どう使う:** 機能を提案する issue の本文に「競合根拠」の節を置き、参考にしたアプリの公式サイトか App Store の URL と、調べた記事の URL を書く。
