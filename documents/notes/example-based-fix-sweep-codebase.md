# 「〜のような箇所を直して」と例で示された修正は、同じ形の箇所をコードベース全体から洗い出して直す

「`list_picker_sheet.dart` の `ref.read(...)` のような箇所を直して」という依頼で、例に挙がった 1 ファイルだけを直して終えたところ、owner から「他にも同じ場所がないか洗い出して、該当するなら直して」と差し戻された。

**なぜ:** 「〜のような箇所」は、その例が代表する同じ形の箇所すべてを直す依頼であることが多い。1 か所だけ直しても依頼を満たさない。変更を必要最低限にする決まりが指すのは 1 か所あたりの変更の量で、対象の箇所をすべて挙げることは依頼の範囲に含まれる。

**どう使う:**

1. 例に挙がった箇所から、直す対象の形を特定する
2. grep でコードベース全体の同じ形の箇所を列挙する
3. 該当する箇所としない箇所に分け、しない箇所には理由を書く
4. 範囲が広い時・判断が分かれる時は、直す範囲を owner に確認してから着手する
