# 0001. グループ名保存: デバウンス+Cloud Function → フォーカスロスト+Firestore直書き

## Status
Proposed

## Context
グループ設定画面のグループ名保存は、Cloud Function (`functions.updateGroupName`) 経由で1秒デバウンスの自動保存を行っていた。しかし以下の問題があった：

- グループ名の更新は単一フィールドの書き換えであり、Cloud Functionを経由する必要がない
- デバウンスによるTimer管理、保存中/完了のインジケーター表示など、UIの状態管理が複雑になっていた
- 入力中にも保存が走るため、意図しないタイミングでの保存が発生しうる

## Decision
以下の2点を変更する：

1. **保存トリガー**: 1秒デバウンス → TextFieldのフォーカスロスト時に保存
   - ユーザーがTextField外をタップした時点で保存される
   - 入力中は保存されないため、意図しない中間状態の保存が起きない

2. **保存経路**: Cloud Function (`functions.updateGroupName`) → Firestore直書き (`runTransaction`)
   - グループドキュメントには `memberUserIDs` 等の共有フィールドがあるため、`runTransaction` で最新データを読み取った上で `copyWith(name: name)` で名前のみ更新する
   - これにより同時書き込みによるデータ消失を防ぐ

## Consequences
- **良い点**: UI状態管理の大幅な簡素化（Timer、保存中/完了インジケーター、lastSavedName が不要に）
- **良い点**: Cloud Functionの呼び出しが減り、レイテンシが低下する
- **良い点**: Firestoreのオフラインキューイングにより、オフライン時の保存も自動的にハンドリングされる
- **トレードオフ**: 保存完了のフィードバック（チェックマークアイコン）がなくなる。ただしフォーカスロスト時の保存はユーザーの明示的な操作に紐づくため、フィードバックの必要性は低い
- **トレードオフ**: 入力中に画面を離れた場合（戻るボタン等）、フォーカスロストが発火するかどうかはFlutterのライフサイクルに依存する
