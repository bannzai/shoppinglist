# Google Play データセーフティ回答チェックリスト

Play Console → ポリシー → アプリのコンテンツ → データセーフティ の回答内容。
画面の流れ順に書いてある。根拠となる実装は `documents/app-privacy-answers.md` を参照。

## 1. 概要の質問

| 質問 | 回答 |
|---|---|
| アプリはユーザーデータを収集または共有しますか？ | **はい** |
| 収集したデータはすべて転送中に暗号化されますか？ | **はい**（Firebase は全通信 HTTPS） |
| データの削除をリクエストする方法を提供していますか？ | **はい**（設定画面にアカウント削除機能あり） |

## 2. データタイプ（チェックを入れるもの）

- [ ] 個人情報 → **メールアドレス**（Apple / Google サインイン経由）
- [ ] 個人情報 → **ユーザー ID**（Firebase Auth の UID）
- [ ] 位置情報 → **正確な位置情報**（店舗のジオフェンス通知用）
- [ ] 財務情報 → **購入履歴**（RevenueCat / プレミアム判定）
- [ ] 写真と動画 → **写真**（レシート・広告を撮影して AI で品名抽出）
- [ ] アプリのアクティビティ → **アプリの操作**（Firebase Analytics）
- [ ] アプリの情報とパフォーマンス → **クラッシュログ**（Crashlytics）
- [ ] アプリの情報とパフォーマンス → **診断**（Crashlytics）
- [ ] デバイス ID または他の ID → **デバイス ID または他の ID**（FCM トークン）
- [ ] その他 → **他のユーザー作成コンテンツ**（買い物リスト・アイテム名・カテゴリ・グループ名・表示名）

上記以外（住所・電話番号・連絡先・カレンダー・SMS・音声・健康・閲覧履歴など）はすべてチェックなし。

## 3. 各データタイプごとの質問（全タイプ共通のパターン）

| 質問 | 回答 |
|---|---|
| 収集ですか、共有ですか？ | **収集のみ**（共有はチェックしない） |
| 一時的に処理されますか？ | **いいえ** |
| ユーザーはこのデータの収集を無効にできますか？（必須 / 任意） | 下表参照 |
| 収集の目的 | 下表参照 |

| データ | 必須 / 任意 | 目的 |
|---|---|---|
| メールアドレス | 必須 | アカウント管理 |
| ユーザー ID | 必須 | アカウント管理、アプリの機能 |
| 正確な位置情報 | **任意**（ジオフェンス通知を使う人だけ） | アプリの機能 |
| 購入履歴 | 必須 | アプリの機能 |
| 写真 | **任意**（レシート読み取りを使う人だけ） | アプリの機能 |
| アプリの操作 | 必須 | 分析 |
| クラッシュログ | 必須 | 分析、アプリの機能 |
| 診断 | 必須 | 分析、アプリの機能 |
| デバイス ID または他の ID | 必須 | アプリの機能（プッシュ通知） |
| 他のユーザー作成コンテンツ | 必須 | アプリの機能 |

## 4. 全体の注意点

- 「共有」はすべて**なし**。Firebase / RevenueCat はデータ処理者（サービスプロバイダ）なので Google の定義では「共有」に当たらない
- 「広告またはマーケティング」目的はすべて**なし**（AdMob 撤去済み）
- プライバシーポリシー URL: `https://bannzai.github.io/shoppinglist/PrivacyPolicy`

## 5. データセーフティ以外の残りフォーム

| フォーム | 回答 |
|---|---|
| アプリのアクセス権 | 「はい」＋ログインの詳細に下記の文言 |
| 広告 | 広告を含まない |
| コンテンツレーティング（IARC） | 暴力・性的表現・冒涜的表現・薬物・ギャンブルすべて「なし」。ユーザー同士の交流のみ「はい」（チャットなし、共有はリスト内容と表示名のみ、位置情報は他ユーザーと共有しない） |
| ターゲット層 | 13 歳以上。子供向けではない |

### アプリのアクセス権「ログインの詳細」に貼る文言

```
サインインは Apple ID または Google アカウントでのみ行えます。
審査用の ID / パスワードは発行できないため、審査担当者ご自身の
Google アカウントでサインインしてください。アカウントの新規作成や
個人情報の入力は不要で、サインイン直後から買い物リストを利用できます。

プレミアム機能（リスト作成数の上限緩和、保存期間の無制限化、
AI によるカテゴリ分けなど）は定期購入が必要ですが、
無料の状態でもアプリの中心機能である買い物リストの作成・共有・
チェックはすべて利用できます。
```

すべて回答すると production の draft リリース（versionCode 35）の「公開」ボタンが押せるようになり、
そこで Google Play の審査が始まる。
